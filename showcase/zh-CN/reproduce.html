代码与复现

环境配置、快速开始与模型复现

先运行标准库检查并预览本地网站。模型复现指南说明原始输入重建、所需本地模型文件及预测命令。现有权重回放已通过；从头重新训练仍未验收。

C+ 是本项目最终模型的简称：RoBERTa 融合 42 项比较特征，再平均三个训练种子的预测概率。

快速开始命令指南
01

环境配置与快速开始

先安装 Git 和 Python 3.11 或更高版本，再克隆仓库。下方检查和本地网页预览只使用 Python 标准库；项目虚拟环境将后续依赖与其他项目分开。

git clone https://github.com/Yemyu/product-entity-matching.git
cd product-entity-matching

macOS / Linux

python3 -m venv .venv
source .venv/bin/activate
python scripts/public_smoke.py
python -m http.server 8000 --bind 127.0.0.1

Windows · PowerShell

py -3 -m venv .venv
.\.venv\Scripts\python.exe scripts/public_smoke.py
.\.venv\Scripts\python.exe -m http.server 8000 --bind 127.0.0.1

冒烟检查会输出 status 为 passed 的 JSON 报告。保持服务器运行，在浏览器打开下方本地项目页；按 Ctrl+C 可停止服务器。

打开本地项目页

下文的 python 指 macOS/Linux 中已激活的项目解释器。Windows 请将 python 替换为 .\.venv\Scripts\python.exe。若通过 ZIP 下载仓库，进入解压后的仓库目录，从环境创建命令开始即可。

准备真实模型输入或运行预测，还需在本地提供商品数据、模型快照和检查点，并在独立项目环境中安装固定的神经网络依赖。文档中的 CUDA 配置已在 Windows 11 的 RTX 3060 上检查。

02

检查公开代码与保存输出

配置好上方环境后，在仓库根目录运行以下检查。程序用合成记录检查输入接口、特征计算和指标算术，并核对保存的聚合结果；无需下载模型或使用 GPU。

01

接口、保存输出与文件检查

public_smoke.py 检查程序包和命令入口；run_notebook.py 运行中英文可执行讲解并核对保存输出；verify_public_release.py 检查公开文件清单、哈希、本地链接与结果算术。passed 表示这些代码和文档检查通过，程序没有运行模型推断。

python scripts/public_smoke.py
python scripts/run_notebook.py
python scripts/verify_public_release.py
02

CLI 帮助与合成输入约定测试

帮助命令列出显式的数据准备、训练与预测入口；测试集检查合成用例。通过这些测试与复现模型实验，是不同的验收。

python scripts/matching.py --help
python scripts/run_tests.py
03

命令的输入与输出

以下命令连接商品对准备、模型训练、预测与评价。实际运行需要本地商品输入、固定依赖及模型文件；命令指南给出了各阶段的文件格式和完整参数。

命令阶段输入处理输出
project-role保留ID、业务视图和原生字段按固定用途投影，拒绝多余字段用途明确的商品对JSON
prepare商品对JSON；非fit复用训练IDF构造x42与AB/BA token；非fit输入不带标签特征、token与准备回执
train训练用途输入、可信模型快照、种子更新编码器和分类头，保存各轮检查点检查点及训练记录
predict / select-epoch检查点、开发输入及独立开发标签先预测，再依pair ID接标签选择共同轮数预测分数与共同E4
calibrate / evaluate校准分数与校准标签；评价分数与评价标签校准锁定阈值，评价复用该阈值阈值文件与聚合指标

04

已核对的现有权重准备与预测

公开代码入口使用原固定输入和本地模型产物运行了 20 条命令，23 组独立核对结果与保存输出一致，最大预测差为 0.0。回放覆盖输入准备与已有模型预测，没有拟合新权重，也没有评价Walmart–Amazon 独立新样本。

  • 准备好的token、42项特征与仅用训练数据拟合的IDF状态
  • 固定MiniLM语义特征与四种对照方法的预测
  • 三个种子的预测与最终集成概率

观察到的环境：Windows 11、Python 3.11.16、PyTorch 2.8.0+cu126与RTX 3060笔记本。其他GPU平台尚未验证。聚合记录保存于fixed-results.json。

05

原实验输入与从头训练

reconstruct-roles 核对原 ZIP 后，恢复四份与冻结文件逐字节一致的角色输入，保留原生字段置空标记。配方只含源位置与哈希，没有商品值或标签。GPU 回放仍需本地快照和可信权重；从头训练与Walmart–Amazon 独立新样本评价尚未验收。

按适用条款在本地提供产物，使用项目环境。训练数据估计参数与 IDF，开发数据选轮数，校准数据选阈值；评价标签与模型输入分离，不用于选择这些设置。接口检查不能补全保存评价池的历史接触记录。

本地静态页面生成

python scripts/build_showcase.py
python scripts/build_showcase.py --check
