数据与方法

数据准备与 RoBERTa 特征融合

归一化生成一致的商品字段视图。42 维比较向量记录字段一致性、差异和缺失状态，RoBERTa 编码两个记录顺序；开发和校准数据分别选择模型检查点与判定阈值。

模型说明

C+ 是本项目最终模型的简称：RoBERTa 融合 42 项比较特征，再平均三个训练种子的预测概率。

输入

一对零售商商品记录。标题、品牌、原生型号和类别组成文本输入；描述、价格、币种及缺失状态通过比较特征参与评分。

模型结构

RoBERTa-base联合编码商品对，将768维文本表示投影为64维，与42项比较特征连接。分类头为106 → 64 → 1，输出一个原始分数（logit）；训练更新编码器与分类头。

评分与判断

每个种子先对AB、BA两个记录顺序的logit取均值，再用sigmoid转成概率。对种子42, 43, 44的概率等权平均；最终分数不小于0.3947772259513537时判为匹配。

01

字段归一化、质量状态与标题 IDF

输入

两条本地提供的零售商记录，包含 title、brand、description、price、priceCurrency，以及原生 modelno、category 字段。

处理

生成业务与原生字段的归一化视图。文本执行 Unicode 归一化、大小写折叠和空白整理；价格解析纯非负数，保留缺失/歧义状态，仅在已知币种相同时允许比较。

输出

包含 pair_id、left、right、left_native、right_native 的商品对记录，以及明确的价格/币种质量状态。不用猜测值替换原来源。

选择依据

标题格式会变化，型号数字或币种不同也可能改变比较对象。分开保存归一化值和不可用信息，避免把缺失价格或两个缺失品牌当作相等的正面证据。

  • 缺失字段

    文本比较采用 Unicode 归一化、大小写折叠和空白整理。缺失的品牌、描述、型号与类别保持缺失，并在已定义的特征位置记录存在指示。两个字段都缺失，不会被计为相等的正面证据。

  • 价格与币种可比较性

    纯非负十进制数可解析为价格。有歧义的符号或分隔符保留为尚未解决的质量状态。仅当两个价格均解析成功且已知币种代码相同，才启用价格相似度；否则可比较价格指示为零。不换算币种，也不填补缺失价格。

  • 标题代码与原生型号

    从标题提取型号样式代码并比较集合，记录完全重合、归一化编辑相似度，以及字母相同数字不同或数字相同字母不同。原生型号独立比较，并检查它是否出现在另一侧记录的标题代码中。

  • 训练记录拟合的标题 IDF

    标题词与字符的文档频次只从训练角色中按内容去重的业务记录拟合。保存的 IDF 在后续角色中为标题重合加权，不重新拟合。标题数字和紧凑标题也做直接比较，这些运算本身不需要拟合。 例如，在100条合成训练记录中，在其中80条记录出现的词权重为1 + ln(101/81) ≈ 1.221，在其中2条记录出现的词为1 + ln(101/3) ≈ 4.517；常见词的重合证据因此较弱。这些频次仅用于教学，不是本数据集统计。

02

训练、开发、校准与评价用途

输入

固定商品对成员及对应的 fit、dev、calibration、evaluation 记录，另有非训练角色的独立标签列表。

处理

在 fit 上拟合参数与标题 IDF，在 dev 上为集成选择共同轮数，在 calibration 上选择阈值，评价时应用这些设置。非训练标签仅在相应指标或选择命令中按 pair_id 连接。

输出

各角色准备输入，以及分开的轮数选择、校准、评价标签。报告评价池包含 555 对，其中 190 对匹配。

选择依据

选轮数与选阈值处理不同的流程问题。分开用途可阻止当前预测接口接收评价标签，但不能证明回顾性评价池此前从未被接触；历史记录仍不完整。

商品对已分配到四种项目用途：训练数据估计模型参数与标题 IDF，开发数据选轮数，校准数据选阈值，评价数据用于报告对照结果。这些角色分配不能证明评价池是未接触的官方测试集，也不能证明实体之间没有重叠。

训练数据

3,738

开发数据

199

校准数据

209

评价数据

555

只有训练模型输入包含目标标签。开发、校准与评价标签保存在独立文件中，由对应命令按 pair_id 与分数连接。非训练角色的准备步骤复用已保存的训练 IDF。这些规则说明当前代码的输入接口，不能重建固定池不完整的历史接触记录。

03

固定顺序的 42 维特征向量

输入

归一化后的业务/原生商品对视图，以及从去重训练记录拟合的标题 IDF。

处理

计算 14 项业务比较、8 项标题 IDF/直接标题比较、8 项标题代码比较、12 项原生型号/类别比较。按 FEATURES.json 固定顺序排列，其他角色复用训练 IDF。

输出

每对一个范围在 [0, 1] 内的有限 x42 向量，包含相似度、存在、不一致与可比较性数值。ID 和目标标签不进入向量。

选择依据

向量明确记录共享型号、数字变化、品牌缺失和价格不可比较等条件。固定顺序让表格对照与神经融合头使用同一含义的比较值。

准备步骤为每个商品对生成 x42 向量。四组分别包含 14、8、8、12 个值，顺序与 FEATURES.json 一致，不包含 ID 或标签。输入缺失时相似度为零，并在已定义的位置用存在或可比较性指示区分。展开各组可查看标识与含义。

04

RoBERTa 文本编码与特征融合头

输入

按 AB 和 BA 两个顺序序列化的品牌、原生型号、类别、标题，以及该对的 x42 向量。

处理

在 256-token 限制内用 RoBERTa-base 编码各顺序，将 768 维首 token 表示投影到 64 个 GELU 单元，与 42 项比较连接，再经过 64 单元 GELU 层、0.1 dropout 和线性输出。

输出

每个种子得到 AB、BA 各一个标量 logit。描述和价格通过 x42 进入分类头，不通过文本序列输入。

选择依据

文本分支表示商品对的语言内容，字段比较保留型号和缺失信息。这是已测试的融合结构；C0 的 AP 接近，限制了本池可以支持的特征贡献结论。

各个种子采用相同结构，分别拥有训练后的参数。文本分支接收品牌、原生型号、类别和标题；比较分支提供 x42，其中包含描述与价格证据。融合头为每个记录顺序输出一个 logit，集成步骤再生成最终商品对分数。

05

方向平均与三种子概率集成

输入

种子 42, 43, 44 的 AB、BA logit，检查点均为开发数据选定的共同第 4 轮。

处理

每个种子内部先平均两个方向的 logit，再计算 sigmoid；随后等权平均三个概率。方向平均在 sigmoid 前，种子平均在后。

输出

每个 pair_id 对应一个连续 C+ 分数，随后用于排序或与校准阈值比较。

选择依据

读取两个顺序使评分对交换左右输入保持对称。三个固定种子的平均定义报告中的集成，不在评价标签上挑选表现最好的种子。

在每个种子内，先求AB与BA的logit均值，再用sigmoid映射成概率。之后对42、43、44三个种子的概率等权平均，得到最终分数。两个操作的顺序固定；不先平均所有logit，也不选择分数最好的一个种子。

pₛ = sigmoid((zₛ,AB + zₛ,BA) / 2)

p = (p₄₂ + p₄₃ + p₄₄) / 3

训练按6轮调度运行，开发数据为三个种子选择共同第4轮检查点。集成分数随后用校准集选定的阈值0.3947772259513537进行判定：分数大于或等于阈值为匹配。阈值不是0.5，也不在评价数据上重选。

06

固定训练设置与选定检查点

输入

先提供校准分数及标签，再提供评价分数和单独保存的评价标签。

处理

依次最大化校准 F1、精确率，再选择较高阈值。C+ 固定使用 0.3947772259513537。按 pair_id 对齐评价分数与标签，AP 按并列分数组计算，P@100 的并列分数按 pair_id 排序，并计算整数混淆矩阵。

输出

555 对上的 C+ AP 0.9660、F1 0.9016、P@100 1.00；TP 165、FP 11、FN 25、TN 354。

选择依据

AP 衡量排序，F1 衡量选定阈值下的判定，P@100 仅描述最前的 100 对。结果属于固定回顾性池，不证明Walmart–Amazon 独立新样本表现；回放一致不等于从头训练或新评价。
