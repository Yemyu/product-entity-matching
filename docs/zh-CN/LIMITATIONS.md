# 解读与局限

[English](../LIMITATIONS.md) | **简体中文**

## 评价范围

报告的指标描述同一批固定的 555 对 Walmart–Amazon 商品记录。这是回顾性比较，历史接触记录不完整。公开代码的角色规则不能证明这批样本在整个开发过程中始终未被接触；尚未建立 Walmart–Amazon 独立新样本或实体不重叠的评价。

AP 0.9660 是排序指标，不是 96.6% 的准确率。F1 0.9016 在校准阈值下计算。P@100 1.00 表示本池排序最前的 100 对都是匹配，不描述全部商品对或未来记录。

## 对照结果与特征贡献范围

C+ 在本池上的 AP 和 F1 高于 L42。C0 独立训练，训练和推断时均将 42 维特征向量置零，其 AP 为 0.9656，与 C+ 接近。仅凭聚合数值不能证明 42 项特征带来了明显的排序增益或统计优势。C0 采用四轮训练与原六轮调度器，在第 4 轮进行比较。

三个训练种子共同定义最终集成，不是三个独立测试群体。公开材料没有单种子不确定性估计或置信区间；保存的聚合数据也不足以生成未保留的 PR 曲线、阈值扫描或错误类型频次。

## 复现范围

公开检查与 Notebook 使用合成输入和保存的聚合结果，验证接口行为及算术，不是重新在商品数据上运行实验。

现有权重回放运行 20 条命令，核对 23 组结果，与固定产物的差值为 0。它验证了公开代码入口能够准备输入并回放原产物，不能代表重新训练。另行完成的原始来源重建已使四份业务输入逐字节一致；这是恢复原成员，不是独立测试。精确模型回放仍需本地快照和可信原权重；原训练权重没有公开下载入口。从头重新训练整套实验尚未验证。

## 环境与用途

观察到的模型环境为 Windows 11、Python 3.11.16、RTX 3060 笔记本及 PyTorch 2.8.0+cu126/CUDA 12.6。其他平台、GPU 与依赖组合尚未验证。直接依赖版本固定文件没有锁定所有间接 wheel 或驱动。

型号后缀冲突、拼写变体和缺失字段仍可能导致错误分数。本项目未测量部署延迟、生产吞吐、校准漂移或业务收益。匹配分数可供核查，本身不足以支持自动合并商品目录；项目不声称方法达到基准领先或已经可用于生产。
