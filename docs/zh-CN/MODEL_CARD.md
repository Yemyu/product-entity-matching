[🌐 English](../MODEL_CARD.md) | **🇨🇳 简体中文**

## 用途与输入

C+ 是本项目最终采用的 RoBERTa 与 42 项比较特征融合模型的简称，为两条商品记录是否指向同一商品评分，用于离线研究。输入包含归一化业务字段、原生型号/类别字段，以及已保存的训练标题 IDF。文本编码器读取品牌、原生型号、类别和标题；描述与价格证据通过比较特征进入模型。

## 文本与特征融合

骨干为 `FacebookAI/roberta-base`，版本 `e2da8e2f811d1448a5b465c236feacd80ffbac7b`。首个 token 的表示为 768 维，经 64 单元 GELU 投影后与 42 项比较特征连接，再进入一个 64 单元 GELU 层、0.1 dropout 和标量 logit 输出。

每条记录采用固定 token 预算：品牌 16、型号 32、类别 16、标题 62，预算包含字段标记。超长标题保留前 40 个和后 22 个 token。每个 AB 或 BA 商品对最多 256 个 token，包含 RoBERTa 特殊 token；缺失文本字段显式写出。

各个种子计算 `p_seed = sigmoid((logit_AB + logit_BA) / 2)`，最终分数等于种子 42、43、44 的概率均值。方向平均发生在 sigmoid 之前，种子平均发生在之后。开发数据选择共同第 4 轮，没有用评价标签挑选种子或轮数。

A、B 分别代表两条商品记录；AB 和 BA 指将它们以两个相反顺序输入。token 是编码器处理的文本单元，可能是单词或单词片段；logit 是映射为概率前的原始分数，sigmoid 将它转换到 0 与 1 之间。训练种子控制随机初始化和数据顺序，本项目平均三个固定种子的概率。

## 固定训练配置

| 设置 | 数值 |
| --- | --- |
| C+ 训练与调度器 | 6 轮 |
| 选定检查点 | 三个种子均为第 4 轮 |
| 微批次 / 有效批次 | 2 / 16 对 |
| 编码器 / 分类头学习率 | 2e-5 / 2e-4 |
| 预热比例 | 10% |
| 权重衰减 | 0.01 |
| 梯度裁剪 | 1.0 |
| 编码器训练 | BF16 autocast；参数为 FP32 |
| 分类头与推理 | FP32 |

[FINAL_MODEL.json](../../reproducibility/FINAL_MODEL.json)记录设置及三个选定检查点的哈希。[ROBERTA_SNAPSHOT.json](../../reproducibility/ROBERTA_SNAPSHOT.json)记录本地骨干文件的哈希。权重和快照文件本身不在此分发，原训练权重没有公开下载入口。骨干来源与本地文件布局见[复现指南](REPRODUCIBILITY.md)。

## 表格对照与消融

| 方法 | 说明 |
| --- | --- |
| B22 | 使用 22 项比较的逻辑回归，固定更新 800 次 |
| L30 | 使用 30 项比较的直方图梯度提升树 |
| S33 | 在 L30 表示上添加三项固定的 MiniLM 语义/缺失特征 |
| L42 | 使用全部 42 项比较的直方图梯度提升树 |
| C+ | RoBERTa 与 42 维特征融合，平均三个种子的概率 |
| C0 | 独立训练的神经对照，保留相同维度，训练和推断时均将 42 维特征向量置零 |

C0 训练了四轮，同时保留六轮调度器，在第 4 轮进行比较；它是实验对照。

## 固定池的保存结果

六种方法都在同一批 555 对回顾性样本上评价，其中匹配 190 对。评价池历史接触记录不完整，Walmart–Amazon 独立新样本表现尚未测试。

| 方法 | AP | F1 | P@100 |
| --- | ---: | ---: | ---: |
| B22 | 0.795590 | 0.743719 | 0.81 |
| L30 | 0.844899 | 0.762115 | 0.90 |
| S33 | 0.846702 | 0.767123 | 0.89 |
| L42 | 0.949700 | 0.852041 | 1.00 |
| C+ | 0.965998 | 0.901639 | 1.00 |
| C0 | 0.965616 | 0.875648 | 1.00 |

C+ 相对 L42 的 AP 提高 **1.63 个百分点**，F1 提高 **4.96 个百分点**。相对 C0，AP 仅高约 **0.04 个百分点**；在各自校准阈值下，F1 高约 **2.60 个百分点**。聚合结果不能证明明显的特征驱动 AP 增益或统计优势。

C+ 阈值为 **0.3947772259513537**，由校准数据选择。评价混淆矩阵的行是真实标签，列是预测标签：

| 真实 / 预测 | 不匹配 | 匹配 |
| --- | ---: | ---: |
| 不匹配 | TN 354 | FP 11 |
| 匹配 | FN 25 | TP 165 |

精确率为 **0.937500**，召回率为 **0.868421**。AP 反映正例排序，F1 受阈值影响，P@100 只描述排序最前的 100 对。各方法完整的精确率、召回率、阈值与样本数见 [fixed-results.json](../../results/fixed-results.json)。

## 验证与使用范围

现有权重回放将 20 条命令的 23 组结果与固定产物核对，差值为 0。[复现指南](REPRODUCIBILITY.md)将这项证据、公开合成检查及尚未验证的完整重训分开说明。快照/检查点哈希识别文件，不证明评价数据此前未被接触。

这批 555 对的比较不衡量延迟、生产吞吐或 Walmart–Amazon 独立样本的泛化。高分本身不足以确定商品目录合并正确。详见[数据卡](DATA_CARD.md)和[局限](LIMITATIONS.md)。[MIT 代码许可](../../LICENSE)不替代第三方模型或数据条款。
